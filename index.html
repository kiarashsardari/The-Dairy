The Dairy چیست؟

The Dairy یک دفتر خاطرات روزانهٔ خط‌فرمانی است که با پایتون نوشته شده. این ابزار با تکیه بر pandas برای ذخیره‌سازی، matplotlib برای نمودار، jdatetime برای تاریخ شمسی و prettytable برای نمایش منو، به شما امکان می‌دهد کارهای روزانه‌تان را ثبت کنید و روند احساساتتان را در طول زمان ببینید.

راه‌اندازی

نصب و پیش‌نیازها

پیش‌نیاز: Python 3.8 یا بالاتر و pip

۱. کلون پروژه → ۲. ساخت venv → ۳. فعال‌سازی → ۴. نصب وابستگی‌ها
۱

کلون کردن پروژه

مخزن را از GitHub کلون کنید یا فایل ZIP را دانلود و خارج کنید.

bash
git clone https://github.com/kiarashsardari/The-Dairy.git
cd The-Dairy
۲

ساخت محیط مجازی

ساخت محیط مجازی اختیاری است ولی پیشنهاد می‌شود.

bash
python -m venv venv
۳

فعال‌سازی (لینوکس / مک)

در لینوکس یا مک محیط مجازی را فعال کنید.

bash
source venv/bin/activate
۳

فعال‌سازی (ویندوز)

در ویندوز محیط مجازی را فعال کنید.

bash
venv\Scripts\activate

نصب وابستگی‌ها

تمام پیش‌نیازها در فایل requirements.txt تعریف شده‌اند:

bash
pip install -r requirements.txt
وابستگی‌های اصلی: pandas برای ذخیره‌سازی، matplotlib برای نمودار، jdatetime برای تاریخ شمسی و prettytable برای نمایش منو.

داده‌ها

ذخیره‌سازی داده‌ها

داده‌ها در فایل my_did.csv با کدگذاری utf-8-sig ذخیره می‌شوند تا در Excel هم بدون مشکل باز شوند.

ستون توضیح
Date تاریخ و ساعت شمسی با فرمت %Y/%m/%d %H:%M
Work شرح کاری که انجام داده‌اید
Grade نمرهٔ احساس از ‎0‎ تا ‎20‎ (نمرهٔ اصلی + 10)
نکته: نمرهٔ اصلی از ‎-10‎ تا ‎10‎ گرفته می‌شود، ولی برای راحتی در ذخیره‌سازی و نمودار، ‎10‎ واحد به آن اضافه می‌شود. خط قرمز روی نمودار در عدد ‎10‎ یعنی حالت خنثی.

نمونهٔ فایل:

my_did.csv
Date,Work,Grade
1403/05/12 21:30,مطالعهٔ پایتون,17
1403/05/12 22:00,پیاده‌روی,14
