# The Dairy 📔

یک دفتر خاطرات روزانهٔ خط فرمانی (CLI) به زبان فارسی که با اون می‌تونی کارهایی که هر روز انجام می‌دی رو ثبت کنی، به حس و حالت از ‎-10‎ تا ‎10‎ نمره بدی و بعداً روند احساساتت رو توی نمودار ببینی.
البته این یک پروژه شخصی هست که برای استفاده خودم ساختم و فقط خواستم به اشتراکش هم بزارم
پروژه با پایتون نوشته شده و از `pandas` برای ذخیره‌سازی، `matplotlib` برای نمودار، `jdatetime` برای تاریخ شمسی و `prettytable` برای نمایش منو استفاده می‌کنه.

## ✨ ویژگی‌ها

- ثبت کارهای روزانه به همراه نمرهٔ احساس (‎-10‎ تا ‎10‎)
- ورودی فارسی با `fa_console`
- تاریخ شمسی با `jdatetime`
- ذخیرهٔ خودکار داده‌ها در فایل `my_did.csv`
- نمایش داده‌های قبلی در قالب جدول
- رسم نمودار خطی و میله‌ای احساسات
- منوی تعاملی با دستورهای فارسی و انگلیسی
- پیام‌های خوش‌آمدگویی هوشمند بر اساس آخرین تاریخ ثبت
- امکان لغو عملیات با `c` یا `ک`

## 🎮 استفاده

برنامهٔ اصلی از طریق فایل `conection.py` اجرا می‌شه:

```bash
python conection.py
```

بعد از اجرا، منوی زیر نمایش داده می‌شه:

```text
+----------------------+--------+
|         عمل          | دستور  |
+----------------------+--------+
| وارد کردن دیتای جدید |   و    |
| نمایش دیتاهای قبلی   |   ن    |
| نمودار احساسات       |   ا    |
| خروج                 |   خ    |
+----------------------+--------+
```

همچنین می‌تونی `brain.py` رو مستقیم هم اجرا کنی:

```bash
python brain.py
```

---

## 🕹️ دستورها

| دستور | کلید فارسی | کلید انگلیسی | توضیح |
|---|---|---|---|
| وارد کردن دیتای جدید | `و` | `sd` | ثبت کار و نمرهٔ احساس جدید |
| نمایش دیتاهای قبلی | `ن` | `sh` | نمایش فایل `my_did.csv` |
| نمودار احساسات | `ا` | `fp` | رسم نمودار خطی و میله‌ای |
| خروج | `خ` | `e` | بستن برنامه |

چند نام دیگه هم به‌عنوان میان‌بر پشتیبانی می‌شن:

- `وارد`، `جدید`، `داداشم`
- `نمایش`
- `نمودار`
- `خروج`، `بیرون`

برای لغو کردن هر مرحله کافیه `c` یا `ک` وارد کنی.

## 💾 ذخیره‌سازی داده‌ها

داده‌ها در فایل `my_did.csv` با کدگذاری `utf-8-sig` ذخیره می‌شن تا در Excel هم بدون مشکل باز بشن.

ستون‌ها:

| ستون | توضیح |
|---|---|
| `Date` | تاریخ و ساعت شمسی با فرمت `%Y/%m/%d %H:%M` |
| `Work` | شرح کاری که انجام دادی |
| `Grade` | نمرهٔ احساس از ‎0‎ تا ‎20‎ (نمرهٔ اصلی + 10) |

> نکته: نمرهٔ اصلی از ‎-10‎ تا ‎10‎ گرفته می‌شه، ولی برای راحتی در ذخیره‌سازی و نمودار، ‎10‎ واحد بهش اضافه می‌شه. خط قرمز روی نمودار در عدد ‎10‎ یعنی حالت خنثی.

نمونهٔ فایل:

```csv
Date,Work,Grade
1403/05/12 21:30,مطالعهٔ پایتون,17
1403/05/12 22:00,پیاده‌روی,14
```

## 📈 نمودار احساسات

با انتخاب گزینهٔ «نمودار» دو نمایش می‌بینی:

1. نمودار خطی روند احساسات
2. نمودار میله‌ای همان داده‌ها

در هر دو نمودار یک خط چین قرمز در عدد ‎10‎ رسم می‌شه که مرز حالت خنثی رو نشون می‌ده.

## 🧠 رفتار هوشمند برنامه

- اگه فایل داده وجود نداشته باشه، پیام خوش‌آمدگویی اولیه نمایش داده می‌شه.
- اگه آخرین ثبت بیش از ۵ روز قبل باشه، پیام «چه عجب از این ورا!» و مشابهش نمایش داده می‌شه.
- اگه بین ۱ تا ۵ روز گذشته باشه، پیام خوش‌آمدگویی معمولی می‌بینی.
- اگه همان روز دوباره وارد بشی، پیام «دوباره سلام!» و مشابهش نشون داده می‌شه.
- بعد از هر ثبت، برنامه با توجه به نمرهٔ احساس، پیام تشویقی یا همدلانهٔ متفاوتی نمایش می‌ده.
